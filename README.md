# Shivanand Pauva House

This project is split into frontend and backend.

## Frontend

The frontend is a React application built with Vite, located in the `frontend/` directory.

To deploy on Vercel:
- Set the root directory to `frontend/` in your Vercel project settings.
- Vercel will automatically detect and build the Vite app.

## Backend

The backend is a Node.js Express server, located in the `backend/` directory.

To run the backend:
- Navigate to `backend/`
- Run `npm install`
- Run `npm start` or `npm run dev`

## Project Structure

```
/
├── frontend/     # React frontend
└── backend/      # Node.js backend
```
